# جدولي — مشروع أندرويد أولي

تطبيق عربي بسيط لهاتف Android، بألوان بنفسجية وبيضاء، مع ويدجت أسبوعي.

## الميزات الحالية
- الأيام: الأحد إلى الخميس.
- حتى 7 حصص في كل يوم.
- إضافة وتعديل وحذف الحصص.
- حفظ البيانات محليًا على الهاتف.
- ويدجت أسبوعي قابل لتغيير الحجم ويعرض الحصص المضافة.
- النقر على الويدجت يفتح التطبيق.

## طريقة بناء ملف APK
1. ثبّت Android Studio على كمبيوتر.
2. افتح مجلد المشروع `JadwaliAndroid`.
3. انتظر مزامنة Gradle وتنزيل أدوات Android المطلوبة.
4. من القائمة اختر Build > Build APK(s).
5. سيظهر ملف APK داخل `app/build/outputs/apk/debug/`.

## إضافة الويدجت على POCO X4 Pro 5G
1. ثبّت التطبيق وافتحه وأضف حصصك.
2. ارجع إلى الشاشة الرئيسية واضغط مطولًا على مساحة فارغة.
3. اختر Widgets / الأدوات.
4. ابحث عن «جدولي الأسبوعي» واسحبه إلى الشاشة.
5. كبّر الويدجت حسب المساحة المتاحة.

## ملاحظات
هذا مشروع بداية قابل للتطوير، وليس ملف APK جاهزًا للتثبيت. يحتاج إلى بنائه في Android Studio. قد يختلف شكل الويدجت قليلًا بحسب إصدار MIUI/HyperOS ومشغّل الشاشة.
